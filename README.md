# Легко дома

Сайт про услуги уборки с интерактивным списком задач. Страница содержит описание услуг, этапы работы и ответы на вопросы.

## Что можно проверить

- Переключить вкладки зон уборки мышью или стрелками с клавиатуры.
- Выбрать две задачи и проверить, что счётчик увеличился до двух.
- Скачать список и сверить содержимое TXT-файла с выбранными задачами.
- Раскрыть ответ на вопрос и проверить, что текст виден.
- Открыть страницу на телефоне и проверить, что содержимое помещается по ширине.
